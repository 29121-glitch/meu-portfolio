Sobre Mim

Minha trajetória de aprendizado, motivações e objetivos no ecossistema de tecnologia.

Minha Jornada

Olá! Sou um estudante apaixonado por tecnologia e criação de soluções funcionais através do código. Minha curiosidade começou ao entender como as páginas e aplicativos que usamos no dia a dia realmente funcionam por baixo dos panos.

Atualmente, tenho investido tempo na prática constante: escrevendo código do zero, consumindo documentações oficiais, versionando no Git e transformando conceitos teóricos em interfaces reais e interativas.

Como Ativar Envio Real por E-mail

Como este é um projeto puramente estático (sem servidor backend próprio), para receber as mensagens reais na sua caixa de entrada você pode usar um destes serviços gratuitos:

  1. Formspree: Cadastre seu e-mail em formspree.io e adicione o atributo action="https://formspree.io/f/seu-id" na tag <form>.
  2. EmailJS: Permite enviar e-mails diretamente com JavaScript puro sem expor senhas.
  3. Link mailto: Você também pode disparar seu cliente de e-mail diretamente com o link acima.

Projeto de Exemplo

Este é um cartão demonstrativo para exemplificar como seus projetos aparecerão.

Como conectar seu projeto real:

  1. Abra o arquivo index.html no seu editor.
  2. Localize a seção <section id="projetos">.
  3. Substitua as tags <button> por <a href="https://seu-link.com" target="_blank"> com a URL do seu deploy ou repositório no GitHub.
  4. Substitua a imagem em assets/ pelo print real da sua aplicação.
